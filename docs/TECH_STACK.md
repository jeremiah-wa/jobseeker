# Jobseeker - Technology Stack

## Confirmed Stack

| Layer | Technology | Notes |
|-------|------------|-------|
| **Deployment** | Docker Compose | Local MVP, cloud later |
| **Backend** | Python 3.11+ | TBD: FastAPI recommended |
| **Database** | PostgreSQL 15+ | With SQLAlchemy ORM |
| **LLM** | Anthropic Claude | Via LangChain abstraction |
| **LLM Framework** | LangChain | Provider-agnostic interface |
| **Initial Region** | Melbourne, AU | Global expansion planned |

## Confirmed Decisions

| Component | Choice | Notes |
|-----------|--------|-------|
| **Web Framework** | FastAPI | Modern, async, auto-docs |
| **Frontend** | React/Next.js | TypeScript + TailwindCSS + shadcn/ui |
| **Auth** | JWT + email/password | passlib + python-jose |
| **CV Parsing** | Hybrid (PyMuPDF + LLM) | PDF only for MVP |
| **PDF Export** | WeasyPrint | HTML/CSS templates |

## API Integrations

### Job Connectors (Priority Order)

1. **Adzuna** (MVP)
   - API: https://developer.adzuna.com/
   - Auth: API key (app_id + app_key)
   - Coverage: AU, UK, US, and more
   - Free tier: 250 calls/day

2. **Jooble** (Phase 2)
   - API: https://jooble.org/api/about
   - Auth: API key
   - Coverage: Global

3. **RemoteOK** (Phase 2)
   - API: https://remoteok.com/api
   - Auth: None (public JSON)
   - Coverage: Remote jobs globally

4. **Indeed** (Phase 3)
   - API: Publisher API (affiliate model)
   - Auth: Publisher ID
   - Coverage: Global

### LLM Providers (via LangChain)

| Provider | Model | Use Case |
|----------|-------|----------|
| **Anthropic** | Claude 3.5 Sonnet | Primary - CV analysis, tailoring |
| OpenAI | GPT-4 | Alternative |
| Local | Ollama/llama.cpp | Offline/cost-sensitive |
